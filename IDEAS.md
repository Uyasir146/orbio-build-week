# Ideas

Directions, not assignments. The best entry will be something nobody on this list thought of.

## Agents that do a job

- **Research desk on tokenised equities.** Web search + PDFs → a daily brief on NVDA, or on whatever trades on Robinhood Chain. Deliver it to Telegram, X, or a voice note.
- **Token launcher.** An agent that launches a token on Pons, writes the story, generates the art, and runs the first week of posts.
- **Content machine.** A topic in, a week of threads, images and short video out, on a schedule. Structured outputs keep the calendar honest.
- **Inbox triage / reply drafter** for a real inbox you own. Boring, valuable, shippable in a day.
- **A coding agent that pays for itself.** Claude Code or Codex on the key, running against a repo on a cron, opening PRs.

## Agents that talk

- **Voice agent** — TTS + STT + a tool or two. A phone-tree that is actually pleasant.
- **NPCs with memory** for a game or a Discord. Structured state, long-running character.
- **A Telegram bot** that answers from your own documents (PDF inputs) and remembers who asked.

## Agents that use the sandbox

- **Browsing agent** in a container: fetch, run scripts, screenshot, report.
- **Data cleaner.** Drop in a CSV, get back a schema, a cleaned file, and a chart.
- **Self-testing code generator** — write, run, read the error, fix, repeat.

## Agents on the rails

- Anything where the agent **claims and rotates its own key** through the Orbio MCP, and holds `$ORBIO` to fund itself. The rails exist; the product on top of them is the entry.

## Small and sharp

- A single-purpose CLI that does one thing brilliantly with one model.
- A browser extension that reads the page you are on and does something useful with it.
- A "one prompt, one artefact" tool — a poster, a report, a song — with structured inputs and a great output.

Whatever it is: use the key from code, ship it public by day seven, and make it something you would use yourself.
